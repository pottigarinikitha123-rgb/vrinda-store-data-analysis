# Vrinda Store Data Analysis

Interactive Excel dashboard analyzing Vrinda Store's annual sales data (~31,000 orders).

## What's inside

`Vrinda_Store_Data_Analysis.xlsx` contains:

- **Vrinda Store** - cleaned raw order data (order ID, customer, gender, age group, date, status, channel, category, size, quantity, amount, shipping location)
- **Pivot analyses** - sales vs orders by month, men vs women sales, order status, top 10 states by sales, age group vs gender, and orders by channel
- **Vrinda Store Annual report** - dashboard with charts and slicers
- **Insights** - key takeaways from the analysis

## Tools

Microsoft Excel: data cleaning, pivot tables, pivot charts, slicers

## How to open

Download the `.xlsx` file and open it in Microsoft Excel to use the interactive dashboard.
